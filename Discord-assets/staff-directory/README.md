# Staff Directory – Variante 05 · Player Cards

## Fertige Boards für Discord

- `boards/staff-leadership-player-cards.png`
- `boards/staff-rocket-league-player-cards.png`
- `boards/staff-management-player-cards.png`

Jedes Board verwendet maximal drei Karten pro Reihe. Bleiben danach eine oder zwei Karten übrig, ist die letzte Reihe mittig ausgerichtet. Die Anordnung ist direkt in die Boards gerendert und wird deshalb von Discord nicht verändert.

## Einzelkarten

Unter `cards/` liegt jede Staff-Karte zusätzlich als eigene PNG-Datei. So können später einzelne Mitglieder ausgetauscht werden, ohne die übrigen Karten neu zu gestalten.

Alle Personenbilder sind neutrale Rückenansichten mit Vectro-Kleidung. Die Namen und Aufgaben im Bereich `Management` sind Beispielangaben.

Hinweis: Discord dokumentiert für eine native Media Gallery keine feste Spaltenzahl oder Ausrichtung einer unvollständigen letzten Reihe. Für die exakt gewünschte Darstellung verwenden die Webhooks deshalb pro Bereich jeweils ein fertig angeordnetes Board.
